# Checklist de lancamento comercial Comunora

Este checklist deve ser usado antes de vender oficialmente para clientes fora do ambiente controlado.

## Produto

- [ ] Cadastro funcionando.
- [ ] Login com Google funcionando ou status de verificacao Google documentado.
- [ ] Pagamento funcionando.
- [ ] Bloqueio por assinatura funcionando.
- [ ] Admin interno com acesso total.
- [ ] WhatsApp conecta por QR Code.
- [ ] Inbox recebe mensagens.
- [ ] Agente responde.
- [ ] Atendente consegue assumir conversa.
- [ ] Google Calendar conecta por usuario.
- [ ] Agenda cria evento.
- [ ] Agenda evita conflito de horario.
- [ ] Lembrete automatico enviado.
- [ ] Respostas `1`, `2` e `3` funcionando.
- [ ] Reativacao de leads configuravel.
- [ ] Campanhas manuais funcionando.
- [ ] Suporte/chamado funcionando.

## Comercial

- [ ] Planos definidos.
- [ ] Limites por plano definidos:
  - numeros de WhatsApp;
  - agentes;
  - usuarios;
  - campanhas;
  - leads;
  - mensagens.
- [ ] Trial definido ou removido.
- [ ] Politica de cancelamento definida.
- [ ] Politica de uso aceitavel definida.
- [ ] Nichos prioritarios definidos.

## Nichos iniciais recomendados

Comece por nichos com agenda e recorrencia. Eles sentem valor mais rapido.

1. Nutricionistas.
2. Cabeleireiros e saloes.
3. Corretores de imoveis.
4. Advogados com triagem de reuniao.

Nao tente vender para "todo mundo" no inicio. Isso dilui mensagem comercial e aumenta suporte.

## Suporte

- [ ] E-mail oficial de suporte configurado.
- [ ] Categorias de chamado definidas.
- [ ] SLA minimo definido.
- [ ] Respostas padrao revisadas.
- [ ] Responsavel por incidentes definido.

## Infraestrutura

- [ ] `app.comunora.com.br` ativo.
- [ ] `api.comunora.com.br` ativo.
- [ ] DNS em Cloudflare.
- [ ] Railway com variaveis revisadas.
- [ ] Webhook Asaas configurado.
- [ ] Webhook Evolution configurado automaticamente por instancia.
- [ ] Google OAuth enviado para verificacao.
- [ ] Backups/restore do banco definidos.

## Criterio para lancar

O lancamento pode acontecer quando:

- um cliente piloto completa o fluxo de ponta a ponta;
- suporte sabe diagnosticar os erros mais comuns;
- pagamento e bloqueio funcionam;
- termos, privacidade e FAQ estao publicados;
- Google OAuth esta aprovado ou a limitacao esta explicitamente comunicada.
